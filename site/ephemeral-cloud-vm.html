Guide · Temporary machines

Ephemeral cloud VMs that delete themselves

Sometimes you need a real Linux machine for an hour: to reproduce a bug on a clean box, run a heavy build, preview a branch, or try something on a GPU. Runlease launches one in your own cloud account with one command and removes it when the lease ends.

One command What people use it for How it goes away Closed by default Questions

One command

$ runlease up -p gcp -n box --ttl 1h -d   # or -p aws
$ runlease exec box -- uname -a
$ runlease connect box                    # a shell
$ runlease down box --yes                 # or let the lease delete it

There is no cluster to keep, no control plane and no account with us. The CLI talks to your cloud, and the machine runs under your own IAM, on your own network.

For anything you repeat, describe the machine in a manifest: size, lease, the setup steps that install your toolchain, and the ports to forward. runlease manifest new writes one.

How it goes away

The lease is two hours unless you set it. A timer on the VM deletes the instance when it ends. On Google Cloud the VM deletes itself through the Compute API. On AWS it powers off, and the instance is set to terminate on shutdown.

That happens with your laptop closed, your network down, or the script that launched it long dead. runlease snooze box 1h moves the deadline when you need longer.

For the cases where a machine is left stopped with a disk still billing, runlease list asks your cloud for every machine carrying the Runlease label and runlease down --leaked removes the stopped ones whose lease is over. It never deletes a running machine.

Closed by default

A temporary machine should not be a temporary hole. With a relay, the VM gets no public address and its SSH server listens on localhost only. The VM dials out to the relay, and you reach it through that tunnel. The relay holds no keys and cannot read the session.

Questions

How is this different from a script that calls my cloud's CLI?

The parts a script usually skips: the machine deletes itself with nothing watching, it has no public address, its host key is known before it boots, and there is one command to find what was left behind.

Do I need Kubernetes or Terraform?

No. One binary on your machine and credentials for one cloud.

What does it cost?

Runlease is free and open source. You pay your cloud the spot price of the VM, shown before launch. More on cost.
